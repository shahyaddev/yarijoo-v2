# Estedad Font Files

Place the Estedad woff2 font files here. Download them from:
https://github.com/rastikerdar/estedad-font/releases/tag/v5.0.2

Required files (weights 300/400/600/700/900):
- Estedad-Light.woff2      (300)
- Estedad-Regular.woff2    (400)
- Estedad-SemiBold.woff2   (600)
- Estedad-Bold.woff2       (700)
- Estedad-Black.woff2      (900)

Until local files are placed here, the CDN import in globals.css
(`@import url('https://cdn.jsdelivr.net/gh/rastikerdar/estedad-font@v5.0.2/css/fontface.css')`)
will serve as an automatic fallback.
